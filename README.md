# Asystent Allegro BOOTSY

**Wersja:** 0.1.0
**Tryb wdrożeniowy:** SHADOW

## Cel aplikacji

Asystent Allegro BOOTSY jest prywatną integracją właściciela konta sprzedawcy BOOTSY. Wspiera analizowanie wiadomości klientów oraz przygotowywanie propozycji odpowiedzi w Centrum Wiadomości Allegro.

Aplikacja jest używana wyłącznie na potrzeby własnego konta sprzedawcy i nie jest udostępniana innym sprzedawcom.

## Zakres działania

Aplikacja może:

* odczytywać wiadomości z Centrum Wiadomości Allegro,
* odczytywać powiązane informacje o zamówieniach, ofertach i przesyłkach,
* przygotowywać propozycje odpowiedzi,
* wysyłać właścicielowi powiadomienia o sprawach wymagających decyzji.

Aplikacja nie obsługuje Dyskusji Allegro.

## Bezpieczeństwo

Na etapie wdrożenia automatyczne wysyłanie odpowiedzi jest wyłączone. Sprawy ryzykowne lub niejednoznaczne wymagają decyzji człowieka.

Repozytorium nie zawiera danych klientów, tokenów dostępu, kluczy API, haseł ani innych sekretów.

## Operator

Operatorem aplikacji jest właściciel konta sprzedawcy BOOTSY. Dane kontaktowe operatora są przypisane do aplikacji zarejestrowanej w Allegro Developer.

Ostatnia aktualizacja: 17 sierpnia 2026 r.
